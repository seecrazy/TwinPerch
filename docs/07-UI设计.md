# UI 设计规范（DesignSystem v1）

> 实现位置：`TwinPerch/Sources/TwinPerchAppCore/DesignSystem.swift`
> 原则：所有视图样式从 DS token 取，禁止散落硬编码。

## 1. 品牌隐喻

"双栖"= 两只鸟共栖一枝。视觉基调 **"安静、私密、有点温度"**：
- 不做 Signal 式的冷技术感，也不做 Between 式的高饱和甜腻
- 隐喻贯穿三处签名时刻（§4），与架构事实呼应（信箱传输、面对面配对、共同领地）

## 2. 色板（双人互补色）

| Token | 值 | 用途 |
|---|---|---|
| `DS.dusk` 黛蓝 | #4A5C7A | 品牌主色、对方气泡基调、强调 |
| `DS.nest` 暮沙 | #D9A86B | 我方气泡基调、品牌提示条 |
| `DS.canvas` | #F7F5F0 | 页面背景（纸感） |
| `DS.surface` | #FFFDF8 | 卡片/气泡底 |
| `DS.bubbleMine` | nest 30% | 我方消息气泡 |
| `DS.bubbleTheirs` | #E6EBF2 | 对方消息气泡 |
| `DS.danger` | #C75047 | 失败/危险操作 |
| `DS.chrome` | 系统 systemBackground | 平台附件底 |

双方气泡各自带一点本方色调（暖=我、冷=TA），替代蓝灰二分。

## 3. 排版与形状

- 品牌时刻（欢迎页、锁屏页、配对页标题）：衬线体 `DS.brandTitle`（serif 34 bold）——中文回退宋体系
- 正文：系统字体（PingFang SC / SF）；等宽仅用于安全码 hex 备查（`DS.mono`）
- 圆角：卡片 `DS.corner`=14，气泡 `DS.bubbleCorner`=16

## 4. 签名时刻

### 4.1 门禁页（锁屏）
蜂鸟图标 + 衬线品牌字 + "只有你们能进的领地" + 黛蓝解锁按钮。
冷启动与后台超阈值（5 分钟）时呈现；`Gatekeeper` 状态机驱动。

### 4.2 面对面配对仪式
两人当面互扫——产品独有的时刻。设计意图：
- 大幅二维码居中（210pt，白底卡片），文案"让 ta 扫这枚码"
- 配对过半即显示安全码卡片（见 4.3），把"共同完成的仪式"可视化为两人共同确认的图案
- 真机扫码走相机（`ios/TwinPerchApp/QRScanner.swift`），桌面为粘贴框——共用 `QRScannerHook` 接入点

### 4.3 安全码可视化
SHA-256(双方公钥) 前 8 字节 → 8 枚成对色块（`DS.safetyGlyphs`，固定 8 色调色板取模）。
两台设备**图案一致**即互信——比比对 16 个 hex 字符体验好一个量级，是隐私产品少有的
"看得见的安全感"。hex 备查收在色块下方小字。

### 4.4 信件隐喻
主干传输即邮箱——消息本质是小信件：纸感画布（canvas 色）、信笺式气泡、
空状态文案走"领地/信箱"语汇。不做拟物过度，质感点到为止。

## 5. 组件清单（DS 内实现）

| 组件 | 说明 |
|---|---|
| `DS.PrimaryButton` | 主按钮，dusk 底、禁用态自动降饱和 |
| `DS.Card` | 纸感卡片（surface + 1px 描边 + 14 圆角） |
| `DS.NoticeBar` | 会话系统提示条（换钥/解密失败，可带动作按钮） |
| `DS.ConnectionBanner` | 连接状态横幅（在线隐藏 / 降级橙 / 离线灰） |
| `SafetyCodeCard` | 安全码色块卡片 |
| `MessageBubble` | 气泡 + 时间戳 + 发送三态（钟表/对勾/双勾/红叹号） |
| `DaySeparator` | 日期分隔条（"M月d日 EEEE"） |
| `QRCodeImage` | CIQRCodeGenerator 渲染（iOS UIKit / macOS AppKit 双路径） |

## 6. 状态语言

- 发送三态：`sending`=钟表，`sent`=对勾，`read`=双勾（dusk 填充），`failed`=红叹号（可点重发）
- 离线文案："消息已排队，恢复后自动送达"（对应发件队列的真实行为，不撒谎）
- 解密失败："收到一条无法解密的消息"+ 一键"请求重同步"

## 7. 决策记录

- **输入状态提示（"正在输入"）不做**：暴露打字时机元数据，与"连回执还是聊天都看不出"的隐私宣称冲突。写入产品页当卖点。
- 通知固定文案"收到新消息"，不带条数与预览（NSE 富预览与生物门禁冲突，二期再评估）。
- 图标：当前用 SF Symbols `bird.fill` 占位；正式 App 图标（两只鸟/栖枝）待品牌设计。
